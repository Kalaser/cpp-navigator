# C/C++ Navigator

C/C++ Navigator 是一个专为大型 C/C++ 项目（如 Linux 内核、RTOS、大型嵌入式项目）设计的轻量级、高性能符号索引与跳转 VS Code 扩展。相比于传统的语言服务器（如 `cpptools` 或 `clangd`），它占用极少的内存和 CPU，同时提供足够精确的跳转体验。

## ✨ 核心特性

- **🚀 极低资源消耗**：采用优化的纯文本异步扫描，彻底告别后台疯狂编译解析导致的卡顿和内存泄漏，非常适合通过 SSH 连接资源受限的云服务器。
- **🧠 智能条件编译识别**：支持 `#ifdef`、`#ifndef`、`#if defined(...)` 等宏定义的条件分支评估，精准过滤未激活的代码块。
- **⚙️ 自动项目环境探测**：自动尝试从工程根目录的 `compile_commands.json`、`CMakeCache.txt` 或 `.config` (Kconfig/NuttX/Linux) 中提取已激活的宏定义。
- **🎯 精准屏蔽噪音**：智能擦除多行/单行注释中的代码，避免跳转到被注释掉的历史代码或产生无效符号。

## 🛠️ 提供的命令 (Commands)

按下 `Ctrl+Shift+P` (Windows/Linux) 或 `Cmd+Shift+P` (macOS) 打开命令面板，你可以使用以下命令：

- **`C/C++ Navigator: Rebuild Index`**
  手动触发重新扫描工作区及所有配置的额外目录，重建符号索引。当项目分支切换、拉取了大量新代码或修改了宏定义配置后，推荐执行此命令以确保跳转准确。

## ⚙️ 扩展设置 (Settings)

你可以通过 `settings.json` 或 VS Code 的设置界面调整以下参数来适配你的项目：

| 设置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `cppNavigator.activeConfigs` | `Array<string>` | `[]` | **激活的条件编译宏**。你可以手动添加激活的宏（例如 `["CONFIG_WIFI", "DEBUG"]`），只有处于这些条件编译分支下的代码才会被解析和索引。 |
| `cppNavigator.extraRoots` | `Array<string>` | `[]` | **额外索引的源码根目录**。如果你的项目引用了工作区之外的 SDK 或第三方库，可以将它们的绝对路径或相对路径添加到此处。 |
| `cppNavigator.excludePatterns` | `Array<string>` | `["**/build/**", "**/out/**", "**/.git/**"]` | **排除扫描的目录规则 (Glob)**。通过排除编译产物和版本控制目录，能大幅加快扫描速度并避免匹配到重复的冗余符号。 |

## 📖 使用指南

1. **自动索引**：安装插件并打开任意 C/C++ 工程后，插件将在后台自动建立索引（VS Code 右下角状态栏会显示“C/C++ Nav: 正在索引...” 及完成后的符号数量）。
2. **快捷跳转**：遇到符号（函数名、宏、结构体、类型等），可以使用常规的 VS Code 快捷键进行操作：
   - **转到定义 (Go to Definition)**: 选中符号按 `F12`
   - **转到声明 (Go to Declaration)**: 右键菜单选择“转到声明”
   - **查找所有引用 (Find All References)**: 选中符号按 `Shift+F12`
3. **增量更新**：每次修改并保存 `.c` 或 `.cpp` 文件时，当前文件中的符号会自动在后台进行增量刷新，无需手动重建全局索引。

## 💡 为什么选择 C/C++ Navigator?

微软官方的 C/C++ (cpptools) 和 clangd 虽然能提供完美的语义分析，但在千万行级别的超级工程（例如 Android 源码、Chromium、Linux Kernel）中，会导致极其漫长的解析时间以及数十 GB 的内存占用。

本扩展旨在成为一种 **“即开即用、清爽畅快”** 的替代方案。通过巧妙的正则优化、条件分支分析和注释擦除，能够在毫秒级延迟内为你提供绝大部分日常所需的代码导航体验。
